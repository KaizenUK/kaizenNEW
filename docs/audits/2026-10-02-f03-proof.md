# F-03: marketing typography

Verified locally 2 October 2026. Production release evidence follows below.

## Change

- Converted the existing Manifa V2 TTF to WOFF2 with FontTools 4.66.1. The font is 25,356 bytes, down from 75,080 bytes, a 66.2% reduction. Character mapping, advance widths and glyph order match the source. The original TTF remains as a fallback.
- Static marketing and ad landing layouts preload the WOFF2. A separate marketing display face corrects the font's unusually small capital height using `size-adjust: 150%`, explicit ascent/descent metrics and no added line gap. Marketing display headings use `line-height: 1.1`. The original unadjusted face remains available outside marketing pages.
- Adjusted the old homepage slogan's responsive size to keep its intended two lines with the corrected font proportions. Balanced wrapped headings and adjusted the WordPress phone heading size to avoid isolated words. The full homepage copy and layout rebuild remains P-01.
- Shared eyebrow styles provide 12px DM Sans, explicit light/dark contrast and consistent weight. Nested dark cards receive the dark variant. Navigation badges cannot shrink into broken words. Removed case-study label monospace styling.
- No public copy, heading level, link destination, metadata or structured data changed. Builder and Studio source are unchanged.

Conversion reference: [FontTools WOFF2 documentation](https://fonttools.readthedocs.io/en/latest/ttLib/woff2.html).
