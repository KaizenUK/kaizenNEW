The other source callers do not produce a scanner in this build. The tool-specific composition uses the F foundations; it does not copy the homepage's bespoke buyer routes or comparison hero, which still await Sean's review.

The PDF now uses plain labels, real test dates, complete page addresses and a paginated findings list. It includes six returned measures and recognises Google's newer finding IDs alongside the earlier IDs. It removes unsupported claims about lost enquiries, promised impact, blanket fixes and perfect scores. An empty list is described as no findings in the checks covered, not proof of an issue-free site. The zero-score band is correct. Editing the input after a run no longer changes the report or saved lead's tested address. Incomplete responses do not leave a partial report visible.

The below-90 email gate, optional marketing choice, browser download and existing save-failure behaviour remain. Opening the report still does not prove a lead was saved; S-04 remains open.
